Annotations

A few stops through reading, comparing and annotating; about two minutes.

Your details

Initials and a date are attached to every annotation, so discussions can be followed. They are kept in this browser.

Shared annotations

Annotations are shared through the project's private Hypothesis group, 1Kb3vwEV (set for you). Paste another group's link or ID only to use a different one, and a personal API token (hypothes.is/account/developer). Without them, annotations are kept as drafts in this browser and can be exported or published later.

An account, the group and your token, step by step.

Colour theme

The colours of the whole bench: listings, annotations and figures. The ◐ button in the top bar switches between your last light and dark themes. The display in Run keeps the DEC 340’s own phosphor.

Reading code

Applies wherever code is shown: listings, comparisons, traces, tables. The A− and A+ buttons in the top bar change the size too.

Figures

The background given to exported figures (PNG and SVG). On a white or paper background figures are drawn in dark ink; on black, in phosphor. Transparent leaves the background empty, for layering in other software.

Developer

Only use if you are developing this software.

Annotate

Unsaved annotation. Save it, or Cancel to discard it.

SHRDLU Research Bench

AuthorDavid M. Berry
Version
Released
PurposeA bench for the critical reading of the SHRDLU source code, made for the Critical Code Studies SHRDLU project (David M. Berry and Mark C. Marino).
Tech stackPlain HTML, CSS and JavaScript; no framework or build step. Runs in the browser from GitHub Pages; annotations via Hypothesis; settings and drafts in local storage; My notes in local storage and kept privately on Hypothesis; Help ▸ Back up everything saves all of it to one file. Built on the Spacewar! Research Bench.
InsideA MacLisp reader and indexer for the source files, and a MacLisp interpreter written for the bench (MacLisp 1.6 and the later MacLisp of the 2024 restoration) that runs SHRDLU in the browser from each version’s own source, with every repair recorded.
SourcesCode by Terry Winograd, revised by Dave McDonald, Jeff Hill, Stu Card and Andee Rubin (MIT AI Laboratory, 1968–77); the MIT files as recovered on ITS and Eric Swenson’s 2024 restoration (PDP-10/its); Winograd’s Stanford distribution. Details under Versions.
