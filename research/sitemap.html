Site map

Every view of the SHRDLU Research Bench as a plain link, for when a menu will not open. The bench runs in JavaScript; without it, the source files below open on GitHub.

Each link opens the MIT files as found on ITS unless it names a version; the version picker at the top of the bench changes it. Any view’s address can be shared as it stands.

Tabs

  • Read: The listing, annotated
